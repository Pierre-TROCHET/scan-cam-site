가이드

iPhone 스캐너로 가장 자주 하는 일들을 단계별로 짧게 안내합니다.

가이드 선택

무료

iPhone에서 여러 페이지를 하나의 PDF로 스캔하는 방법

모든 페이지를 한 문서로 스캔한 다음, 하나의 PDF로 공유하세요.

 무료

iPhone에서 영수증을 스캔하고 정리하는 방법

종이 영수증을 선명하게 사본으로 만들어 정리하고, 필요한 사람에게 보내세요.

 Pro

iPhone에서 손가락으로 문서에 서명하는 방법

서명을 한 번 그리거나 촬영해 두고, 어떤 문서에든 넣으세요.

 Pro

iPhone에서 스캔한 문서의 텍스트를 복사하는 방법

인터넷 없이 휴대폰에서 페이지를 읽고 텍스트를 복사하세요.

 Pro

iPhone에서 PDF 파일을 병합하는 방법

여러 문서를 원하는 순서대로 하나의 PDF로 합치세요.

 Pro

iPhone에서 PDF의 페이지를 추출하는 방법

고른 페이지로 새 문서를 만들고 원본은 그대로 보관하세요.

 Pro

iPhone에서 PDF에 워터마크를 넣는 방법

문서의 모든 페이지에 원하는 문구를 넣으세요.
